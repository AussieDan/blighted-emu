How Studio works

Studio changes the game world with no code. Each change is one small design file in the content/ folder of this checkout. The game data of the client is never changed.

  1. Pick a kind in the Editor: AI profile (how a mob acts: wander, guard, patrol or idle), Path (a walk route for a patrol) or Spawn group (new mobs at points you pick).
  2. Fill in the fields. For a path or a spawn group, right-click the map to add a point. Undo point and Clear points fix mistakes.
  3. Save. The file shows in Design files. The game does not change yet.
  4. Apply (top right). It checks every design file, writes the merged game data, and restarts the local world. If a check fails, Problems lists it, and Apply writes nothing.

Items, loot, mobs and quests are changed on the Records page. Block scripts are on the Scripts page. Every file format is in content/README.md.
